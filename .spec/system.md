# The Soul

## Architecture
This is a static HTML/CSS website for Roots Brotherhood, a community interest organization.
It serves as a central hub for information about the mission, events, donations, and ways to get involved.

## Core Logic
The website consists of static pages (`index.html`, `privacy.html`, `terms.html`) styled with custom CSS and external fonts/icons.
Content sections include About, Our Story, Mission, Merch, Join, News (Instagram widget), and Resources.

## Intent & Vibe
To promote mental well-being and community engagement among men. A safe, non-judgmental community space.

## Invariants & Quality Bar
- The site must be responsive and user-friendly.
- Must load quickly (lazy load non-critical assets).
- HTML must be semantically correct.
